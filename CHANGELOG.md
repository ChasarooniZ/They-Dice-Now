## 0.1.0

- **Public Release**
  _This module creates a little 2d dice animation with a number on it everytime someone rolls a dice in fvtt_
- **Features**
  - `Ghost Dice` - Show Grey die with no results if you don't have access to the die result
  - `Die Border` - Option to add a Dice border, as well as player specific dice borders
  - `Avoid Windows` - Option to make the dice avoid open windows
  - `Avoid Dice` Option to make the Dice Avoid eachother in the same window
- **Configurable**
  - Dice Size, Text Size, Roll Duration, Display Duration, Delay between dice, Show Dice above the UI
